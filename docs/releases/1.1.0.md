## 新しくなったこと

- 「このポストに興味がない」のワンクリックボタンを追加しました。ミュートと合わせて、ポストをその場で整理できます。
- アイコンを作り直しました（X ブルーの角丸バッジに、白いミュート記号。16 / 32 / 48 / 128 px）。

## 直したこと

- 押したボタンと違う項目（「ミュート」ではなく「ミュート解除」など）が実行されることがあったのを直しました。項目の探し方を、`data-testid` → 文言の完全一致 → 部分一致の順にし、似た項目を除外しています。
- 連打したときにメニューを取り合って失敗することがあったのを直しました（操作を順番に処理します）。
- スクロールしてポストが入れ替わったときに、ボタンが消えたり別のポストに残ったりすることがあったのを直しました。
- 失敗したときに、開いていたメニューの項目をトーストに出して、原因が分かるようにしました。
