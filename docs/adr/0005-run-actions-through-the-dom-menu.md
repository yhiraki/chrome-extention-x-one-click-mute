# 0005 実行は X の内部 API ではなく、DOM のメニュー項目のクリックで行う

## 背景

「ミュート」「このポストに興味がない」を実行する方法は 2 つ考えられる。X の内部 API（GraphQL）を直接呼ぶか、X 自身の「…」メニューを開いて項目をクリックするか。

## 決定

- 「…」（`[data-testid="caret"]`）をクリックしてメニューを開き、目的の項目を探してクリックする。
- メニューの開閉は `Escape` で行い、開く前に他のメニューが開いていれば閉じる。
- 連打してもメニューを取り合わないよう、操作は直列のキューで処理する。

## 検討した案

- X の内部 API を直接呼ぶ案: エンドポイントと bearer トークン、`ct0` などの取得と追随が要るうえ、X 側の変更に弱いので見送った。
- キーボードショートカットを送る案: フォーカス位置と UI 言語に依存し、確認画面が出たときの扱いも増えるので見送った。
- X のメニューを自前で描く案: 同じ見た目を作り続ける負担が大きく、項目が増えたときに追随できないので見送った。

## 影響

- 見た目と処理は X のメニューに従う。X が項目を消したり名前を変えたりすると動かなくなる（そのときはトーストに項目の一覧が出る）。
- 確認ダイアログが出る操作には、いまのところ対応していない（`docs/issues/0001` で実機確認する）。
