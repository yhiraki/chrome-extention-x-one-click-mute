# 0004 メニュー項目の照合は data-testid、完全一致、部分一致の順に行い、除外語で取り違えを防ぐ

## 背景

「ミュート」を押したのに「ミュート解除」が実行される、といった取り違えが起きうる。X のメニューの文言は表示言語で変わり、同じメニューに「ミュート」と「ミュート解除」のように似た項目が並ぶこともある。

## 決定

- 目的の項目は、次の順で探す。
  1. `data-testid` の一致（`mute`、`uninterested` など。表示言語に依存しない）
  2. 正規化したテキストの完全一致
  3. 正規化したテキストの部分一致
- 正規化では、大文字小文字、空白（全角・NBSP を含む）、引用符、句読点・記号を落とす。
- 除外語（`unmute`、`ミュート解除`、`解除` など）に当たる項目は、どの段でも選ばない。
- 見つからなかったときは、開いていたメニューの項目を全部トーストに出して、あとから文言を足せるようにする。

## 検討した案

- 部分一致だけで探す案: 「ミュート」が「ミュート解除」に当たるので見送った。
- 表示言語を固定して完全一致だけで探す案: X の言語設定を変えたときに動かなくなるので見送った。
- メニュー項目の並び順で選ぶ案: 項目の順は X 側の都合で変わるので見送った。

## 影響

- 対応する言語を増やすときは `content.js` の `ACTIONS` に文言を足す。`data-testid` が分かっていれば文言は要らない。
- 見つからなかったときのトーストは、実機で文言を確かめる手がかりになる。
- 照合のロジックは今のところテストが無い（`docs/issues/0002` で切り出す）。
