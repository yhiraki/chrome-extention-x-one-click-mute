# 0003 注入済みの判定は、ポストの要素ではなくステータスの URL で行う

## 背景

X のタイムラインは仮想スクロールで、画面から外れたポストの要素を別のポストに使い回す（React の再利用）。要素に印だけを付けて「もうボタンを足した」と判断すると、使い回された別のポストに前のポストのボタンが残る。

## 決定

- ポストごとに、`a[href*="/status/"]` からステータスの URL を取り、それを識別子にする。
- 注入したことを `WeakMap`（ポストの要素 → `{key, container}`）で覚え、いまの識別子と違っていたら、古い入れ物を外して入れ直す。
- アクションバーの中に自分の入れ物が残っていれば、二重に足さない。

## 検討した案

- 要素に印を付けるだけで済ませる案: 使い回しで別のポストに移るので見送った。
- 定期的に全部のボタンを外して足し直す案: 押している最中に外れることがあり、スクロールの間も無駄に DOM を触るので見送った。
- ステータスの URL ではなく本文の文字を使う案: 本文は編集や翻訳で変わるので見送った。

## 影響

- 同じポストが複数回描画されても、ボタンは 1 組だけになる。
- 識別子はポストの要素の外にあるので、要素が作り直されても正しく判断できる。

なお、この記録は 2026-10-19 の作り直しのときに、それまでの実装が結果的に取っていた形を書き残したものである。
