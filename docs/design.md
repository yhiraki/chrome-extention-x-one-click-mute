# X One-Click Mute 設計書

## 1. 目的とゴール

- **目的**: X（Twitter）のタイムラインのポストを、ワンクリックで「ミュート」「このポストに興味がない」にできるようにする。X 自身の「…」メニューを開いて項目を探す 2 クリックを、1 クリックにする。
- **ターゲット**: 作者本人（1 人）。Chrome に手動で読み込んで使う。
- **前提**: Manifest V3。X の DOM 構造に依存するため、X 側の変更で壊れることがある。

## 2. 画面構成

### 2.1 ポストのアクションバーのボタン

- 各ポスト（`article[data-testid="tweet"]`）のアクションバー（`div[role="group"]`）の末尾に、2 つのボタンを足す。
  - 🚫 ミュート（X の警告色のピンク）
  - ⊖ このポストに興味がない（X の青）
- アイコンの色は、そのアクションバーの返信・いいねボタンの色を読んで合わせる（ライト / ダーク対応）。JS が `--xoc-base` を渡し、見た目は `styles.css` が持つ。
- 押すと淡く（`xoc-busy`）、成功すると短く緑（`xoc-done`）になる。失敗すると赤いトーストで理由を出す。
- キーボード（Enter / Space）でも押せる。

### 2.2 トースト

- 失敗したときだけ、画面の下部に 4 秒間出る（`#xoc-toast`）。成功はボタンの色だけで知らせる。

## 3. 設定とアセット

- 設定は持たない（`chrome.storage` を使わない）。常に両方のボタンを出す。
- アイコンは `icons/icon16|32|48|128.png`。作り直しは `tools/make-icons.ps1`（X ブルーの角丸バッジに、白いミュート記号）。

## 4. API

- X の内部 API は呼ばない（`docs/adr/0005`）。DOM の「…」（`[data-testid="caret"]`）をクリックしてメニュー（`[data-testid="Dropdown"]`）を開き、`[role="menuitem"]` の中から目的の項目を探してクリックする。
- 項目の探し方は、`data-testid` の一致、テキストの完全一致、テキストの部分一致の順。テキストは正規化して比べ、除外語（`ミュート解除`、`Unmute` など）に当たる項目は選ばない（`docs/adr/0004`）。
- 連打してもメニューを取り合わないよう、操作は直列のキューで処理する。

## 5. 認証

- 拡張自身は認証を持たない。X のページで動くので、操作はそのページのログイン状態で実行される（未ログインなら X 自身がログインを求める）。

## 6. 配備

- Chrome に「パッケージ化されていない拡張機能」として読み込む（`chrome://extensions`）。Chrome ウェブストアには出さない。
- 変更したら、拡張機能の再読み込みと X の再読み込みが要る。
- バージョンの原本は `manifest.json`（`docs/adr/0006`）。`npm run version:patch|minor|major` で `package.json` と一緒に上げてタグを付ける。
