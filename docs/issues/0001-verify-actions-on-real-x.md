# 0001 本物の X で「ミュート」「このポストに興味がない」が実行できることを確かめる

## 背景

X の DOM を模したページと、確認用のブラウザ（ログアウト）では、メニューの開閉と項目の照合までしか確かめられない。本物の X でボタンを押したときに「ミュート」「このポストに興味がない」が実行され、確認画面が出ないかは確かめていない。

## やること

- ログインした Chrome で、タイムラインのポストのボタンを押し、ミュート / このポストに興味がないが実行されることを確かめる。
- 確認ダイアログが出る場合は、その文言と、押したあとのメニューの状態を控える。
- 表示言語を変えたとき（英語など）も、メニューの項目を取れることを確かめる。

## やらないこと

- 確認ダイアログの自動処理（出ることが分かってから、別の issue にする）。

## 検討した案

- ログイン済みのブラウザを自動で用意する案: 認証情報を置けないので見送った。
- メニューの項目名を先に全部書き足す案: 実機で見た項目名から足すほうが確実なので、確認を先にする。

## 完了の条件

- [ ] 実機（ログイン済みの Chrome）で、ミュートが実行されたことを確かめた
- [ ] 実機で、このポストに興味がないが実行されたことを確かめた
- [ ] 表示言語を変えたときのメニューの項目名を控え、足りない文言があれば `content.js` に足した
- [ ] 決めた振る舞いをテストで確かめている（自動化できないため、確認した手順をこの issue に残した）
- [ ] ADR なし
- [ ] `docs/design.md` に関わる変更なし

## 未決事項

- 確認ダイアログが出る操作への対応（出す / 自動で確定する）。
- 実行後にそのポストをタイムラインから消すかどうか（X は「興味がない」でもすぐには消えないことがある）。
